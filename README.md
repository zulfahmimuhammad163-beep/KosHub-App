## 📌 Tentang Aplikasi
KosHub menghubungkan calon penghuni dengan pengelola kos dalam satu alur: 
`lihat kamar` → `ajukan booking` → `persetujuan` → `bayar & unggah bukti` → `verifikasi` → `data penghuni`.

## ✨ Fitur Utama
- Katalog dan pencarian kamar
- Booking dengan persetujuan pengelola
- Unggah dan verifikasi bukti pembayaran
- Notifikasi otomatis
- Pengelolaan data kamar dan penghuni
